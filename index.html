How to install (about 1 minute)

  1. Download the zip

    Click the button above. The file “Folder-Locker.zip” is saved in your Downloads folder.

  2. Extract it

    Right-click the zip, choose “Extract All…”, then “Extract”. Do not open the app from inside the zip.

  3. Open Folder Locker

    Open the new folder and double-click FolderLocker (padlock icon). Keep all the files in that folder together. Nothing is installed, so you can keep the folder on your Desktop or anywhere you like.

  4. If Windows shows a warning

    If you see “Windows protected your PC”, click “More info”, then “Run anyway”. Windows shows this for new apps that are not signed with a paid certificate. Only run files you downloaded from this page.

How to use it

Lock a folder in three steps. Unlocking is the same in reverse.

  1. Choose a folder

    Click Browse, or just drag the folder into the app window.

  2. Set a password

    Use 8 or more characters. The strength bar helps, and you type it twice so a typo cannot lock you out.

  3. Press “Encrypt and lock”

    If “Create a recovery key” is ticked, the app first shows your key so you can save it (see below). Then your folder turns into one file, for example Private.vault. It appears in the same place the folder was, and Explorer opens to show it.

To unlock

Open the “Unlock a vault” tab, choose or drag the .vault file, enter the password, and press Unlock. Your folder comes back in the same place.

Forgot the password? Type your recovery key in the same box instead.

Before you lock

The original folder is removed after locking. Keep a copy of important files somewhere else first.

Without the password or the recovery key, nobody can open the vault.

Saving your recovery key: choose the location carefully

The key is shown only once, before the folder is locked. Use “Copy” or “Save as text file” and keep it somewhere safe.

Do not save the key file inside the folder you are locking. That folder is locked away, so the key file would be locked inside the vault with it, and you could not read it when you need it. Windows often opens the Save window in the last folder you used, so check the location every time. The app also warns you if you pick a place inside the locked folder.

Good places: a USB drive, your cloud storage, a password manager, or a printed copy. Do not keep it right next to the .vault file.

Questions

Quick answers.

Where did my locked folder go?

It became a single file named after the folder, like Private.vault, in the same place the folder was. The app opens Explorer and highlights it when locking finishes. To find all vaults, search for *.vault in Explorer.

I forgot my password. Can I get my files back?

Yes, if you created a recovery key when you locked the folder. On the “Unlock a vault” tab, type the recovery key into the password box. Without the password and without the key, nobody can open the vault, including the author.

Where should I save my recovery key?

Somewhere safe that is not inside the folder you are locking, because that folder gets locked away together with the key file. A USB drive, cloud storage, or a password manager is a good choice. Also avoid keeping it right next to the .vault file.

I lost my recovery key. Can I make a new one?

Unlock the vault with your password, then lock the folder again. A fresh recovery key is created each time you lock.

Do vaults made with an older version still work?

Yes, they open with their password as before. They have no recovery key, so lock the folder again with the new version if you want one.

Windows says “Unknown publisher”. Is that normal?

Yes, for new apps that are not signed with a paid certificate. Click “More info”, then “Run anyway”. Download the app only from this page.

My antivirus flagged the app. Is it a virus?

It is a known false alarm for new, unsigned apps. Folder Locker encrypts a folder and removes the original, which some antivirus programs mistake for ransomware behavior. The source code is open on GitHub, and you can allow the file in your antivirus or report it as a false positive.

Does it need internet or an installer?

No. Folder Locker works offline and nothing is installed. Delete the folder to remove it.

Can I open a .vault file with another program?

No. The file names inside are hidden and encrypted, so it opens only in Folder Locker with the right password or recovery key.
